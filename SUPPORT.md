# Support

This is a personal project. Support is best-effort.

## Getting help

- **Documentation**: [README.md](README.md), [CLAUDE.md](CLAUDE.md), [000-docs/](000-docs/)
- **Bug reports**: [Open an issue](https://github.com/jeremylongshore/contributing-clanker/issues/new?template=bug_report.md)
- **Feature requests**: [Open an issue](https://github.com/jeremylongshore/contributing-clanker/issues/new?template=feature_request.md)
- **Security issues**: See [SECURITY.md](SECURITY.md) — do NOT open public issues

## Response times

| Channel | Best-effort response |
|---------|---------------------|
| Security reports | 24 hours |
| Bug reports | 1 week |
| Feature requests | 2 weeks (may be deferred) |

## Before opening an issue

1. Search [existing issues](https://github.com/jeremylongshore/contributing-clanker/issues)
2. Confirm the bug reproduces with the latest version of the `/contribute` skill + dossier system
3. Include version info (`bd version`, `gh --version`, last researcher-build.sh run timestamp) and reproduction steps
